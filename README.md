# 🎁 群抽奖系统 GroupLottery

AstrBot 群聊抽奖插件：**发布抽奖 → 群友报名 → 手动 / 定时 / 满员自动开奖 → 群内公布中奖名单**，
并支持「密钥奖品」——机器人把专属兑换码**私聊**发给中奖者，群里只公布名字、绝不明文泄露密钥。

> 包名：`astrbot_plugin_group_lottery`

## ✨ 功能一览

- **发布抽奖**：管理员一条指令发布，可设奖品名、中奖名额、奖品说明
- **报名参与**：群友发送「抽奖 参与」报名，可随时「抽奖 退出」
- **三种开奖方式**
  - `抽奖 开奖` —— 管理员随时手动开奖
  - `抽奖 定时 20:00` —— 到点自动开奖（支持 `+2h` / `12-31 20:00` / `2026-12-31 20:00`）
  - `抽奖 满员 10` —— 报名满 10 人立即开奖
- **两种奖品形态**
  - **普通奖品**：群里公布名单并提示联系群主 / 管理员领取
  - **密钥奖品**：管理员粘贴一批密钥，开奖后机器人**逐个私聊**发给中奖者
- **开奖公告**：真实 @ 中奖者（OneBot 系），不支持的平台自动降级为文本昵称
- **自助补领**：私聊发送失败时，中奖者可在群里或私聊发送「抽奖 领取」补领密钥
- **密钥绝不上群**：公告、名单、状态里都不会出现密钥明文
- **可视化管理面板**：总览统计 / 抽奖场次 / 中奖记录 / 密钥池（密钥默认打码，点击显示）
- **重启不丢**：定时任务存库，插件重启后自动恢复；停机期间错过的开奖会补开
- **群黑白名单**、额外管理员、自定义公告模板与私聊模板

## 📦 安装

1. 在 AstrBot 插件市场搜索 `group_lottery` 安装，或把本仓库放进 `data/plugins/astrbot_plugin_group_lottery`
2. 无需额外依赖（只用 Python 标准库 `sqlite3` / `random` / `asyncio`）
3. 在 WebUI 插件配置页填写「群主联系方式」，其余保持默认即可

## 🚀 上手

两条路都行，**管理员可以全程待在私聊里跨群管理**。

### 路线 A：全在私聊（推荐，密钥不会碰到群聊）

```
你 → 机器人（私聊）
抽奖 发布 123456 月卡 3      # ① 在群 123456 发布抽奖，并自动在该群播报
抽奖 密钥 123456             # ② 另起一行粘贴密钥
ABCD-1111-2222
EFGH-3333-4444
抽奖 定时 123456 20:00       # ③ 今晚 20:00 自动开奖
抽奖 开奖 123456             # 或者随时手动开奖
```

发布时会先确认**机器人确实在群 123456 里**（OneBot 系通过群列表校验），然后：

- 私聊回复你「抽奖已发布」
- 在群 123456 里自动播报一条抽奖信息（群里看不到你的命令痕迹）

**选项可以一口气写完**，不用分几次发：

```
抽奖 发布 754797467 支付宝口令红包5元 2 定时 20:00 满员 8 说明 手慢无
```

| 选项 | 说明 |
|---|---|
| `名额 <数字>` | 中奖名额，等价于写在奖品名后面的位置参数 |
| `定时 <时间>` | 自动开奖时间：`20:00` / `+2h` / `12-31 20:00` |
| `满员 <人数>` | 报名满 N 人提前开奖；`满员 关` 关闭 |
| `私聊 开\|关` | 是否私聊中奖者发密钥 |
| `说明 <文本>` | 补充说明，会显示在状态和群公告里 |

位置参数 `[名额]` 和 `名额` 选项都行，同时写时以 `名额` 选项为准。奖品名里带数字不会被误判（`5元红包 2` → 奖品「5元红包」，2 个名额）。

### 路线 B：在群里发布

```
/抽奖 发布 月卡 3 定时 20:00 满员 8   # 群里直接发布，同样支持一行式选项
```

密钥仍然**必须走私聊**：

```
你 → 机器人（私聊）
抽奖 密钥 123456
ABCD-1111-2222
EFGH-3333-4444
```

### 群友参与

```
/抽奖 参与                   # 报名
/抽奖 状态                   # 看奖品、名额、开奖时间、已报名人数
```

### 开奖时会发生什么

1. 从报名名单里随机抽出中奖者
2. **先私聊**把密钥发给每位中奖者
3. **再在群里**公布中奖名单并 @ 中奖者；若有人没收到私聊，公告里会点名提示他们私聊机器人发送「抽奖 领取」补领

> ⚠️ 如果管理员不小心把密钥发到了群里，插件会**拒绝入库**并**尝试撤回那条消息**（OneBot 平台且机器人有撤回权限时），然后回复正确的私聊操作指引。

## ⌨️ 命令表

主命令：`抽奖`（英文别名 `lottery` / `raffle`）。

**群里用**：直接操作当前群，不需要写群号。

**私聊用**：把**群号**写在子命令后面，可以跨群管理（仅限全局管理员）。

> 💡 **只读命令可以省略群号**：私聊里直接发 `抽奖 状态` / `抽奖 名单` / `抽奖 密钥 查看`，
> 会套用你**最近发布过抽奖的那个群**，回复里会写明用的是哪个群。
> 会改动状态的命令（`开奖` / `取消` / `定时` / `名额` / `密钥 清空` 等）**必须写明群号**，
> 不会猜 —— 免得改错群。忘了群号时，报错信息里会列出你最近操作过的群。

| 群里写法 | 私聊写法 | 权限 | 说明 |
|---|---|---|---|
| `抽奖 帮助` | 同左 | 所有人 | 查看全部命令 |
| `抽奖 参与` / `抽奖 报名` | — | 所有人 | 报名参加当前抽奖 |
| `抽奖 退出` | — | 所有人 | 取消自己的报名 |
| `抽奖 状态` | `抽奖 状态 [群号]` | 群里所有人 / 私聊全局管理员 | 奖品、名额、开奖时间、报名人数、密钥剩余量 |
| `抽奖 名单` | `抽奖 名单 [群号]` | 同上 | 查看已报名成员 |
| `抽奖 记录` | `抽奖 记录`（看自己的） | 所有人 | 本群最近的开奖结果 |
| `抽奖 领取` | `抽奖 领取` | 所有人 | 补领未收到的密钥；私聊发送可直接取回密钥 |
| `抽奖 发布 <奖品名> [名额] [选项…]` | `抽奖 发布 <群号> <奖品名> [名额] [选项…]` | 群里管理员 / 私聊全局管理员 | 发布抽奖，选项可一次写完；私聊发布时会在群里自动播报 |
| `抽奖 密钥 查看` / `抽奖 密钥 清空` | `抽奖 密钥 [群号] 查看` / `抽奖 密钥 <群号> 清空` | 同上 | 查看 / 清空密钥池（都不含密钥明文）；查看可省略群号，开奖后自动回退到最近一场 |
| — | `抽奖 密钥 [群号]` + 换行粘贴密钥 | 全局管理员 | **设置密钥池（唯一入口，必须私聊）**；可省略群号 |
| `抽奖 名额 <数字>` | `抽奖 名额 <群号> <数字>` | 同上 | 修改中奖名额 |
| `抽奖 定时 <时间>` / `抽奖 定时 关` | `抽奖 定时 <群号> <时间>` | 同上 | 设置 / 取消自动开奖时间 |
| `抽奖 满员 <人数>` / `抽奖 满员 关` | `抽奖 满员 <群号> <人数>` | 同上 | 设置 / 取消满员提前开奖 |
| `抽奖 私聊 开\|关` | `抽奖 私聊 <群号> 开\|关` | 同上 | 是否私聊中奖者发密钥 |
| `抽奖 说明 <文本>` | `抽奖 说明 <群号> <文本>` | 同上 | 补充奖品说明 |
| `抽奖 开奖` | `抽奖 开奖 <群号>` | 同上 | 立即开奖并公布结果 |
| `抽奖 取消` | `抽奖 取消 <群号>` | 同上 | 取消当前抽奖 |

**权限说明**

- **管理员**（群里）：AstrBot 全局管理员、群主、群管理员，以及插件配置里补充的 QQ 号。
- **全局管理员**（私聊）：仅 AstrBot 全局管理员 + 插件配置里的 QQ 号。

  为什么更严？私聊里拿不到「群主 / 群管理员」身份，而按群号操作等于**跨群写权限**——如果放开，任何人都能私聊机器人给别的群发抽奖。群主 / 群管理员请直接在本群操作。

### 时间写法

| 写法 | 含义 |
|---|---|
| `20:00` | 今天 20:00，已过则顺延到明天 |
| `+30m` / `+2h` / `+1d` / `+90s` | 相对当前时间（也支持 `+2小时`） |
| `12-31 20:00` | 今年 12-31，已过则顺延到明年 |
| `2026-12-31 20:00` | 指定日期时间（`/` 分隔也支持） |

| 占位符 | 内容 |
|---|---|
| `<winners>` | 中奖名单（开启真实 @ 时为纯昵称，否则为 `@昵称`） |
| `<count>` | 中奖人数 |
| `<prize>` | 奖品名 |
| `<group>` | 群号 |

## 🎛️ 管理面板

在 AstrBot 面板的插件页打开「群抽奖系统」，提供三个标签页：

- **总览**：群数 / 进行中 / 累计场次 / 中奖人次 / 密钥剩余 + 进行中的抽奖（可直接开奖、取消）+ 最近中奖
- **抽奖场次**：按状态与群号筛选；点「详情」查看基本信息、密钥池（可在线粘贴保存）、中奖名单、密钥明细（点击显示明文）、报名名单
- **中奖记录**：全部中奖历史，含密钥与私聊送达状态

## 🧠 设计说明

- **密钥只能私聊设置**：群聊里发「抽奖 密钥 &lt;内容&gt;」会把明文暴露给全群，因此插件拒绝入库，并尝试撤回那条消息（OneBot 平台且机器人有撤回权限时），然后回复正确的私聊操作指引。群里只保留「查看 / 清空」两个不含密钥内容的命令。
- **期号按群独立**：`第 N 期` 是**本群内**的编号，从 1 开始，不会因为别的群发过抽奖而变成「第 47 期」。内部仍用全局自增主键关联参与者 / 密钥 / 中奖记录，两套编号互不干扰。
- **按群号跨群管理**：私聊命令用群号定位目标群，而不是内部期号——期号是展示用的，还得先回群里查。发布前会校验机器人在该群中（OneBot 走 `get_group_list`；其它平台退化为「该群此前有过抽奖记录」，否则拒绝并提示）。
- **私聊发布自动播报**：从私聊发布时群里看不到任何命令痕迹，因此插件会额外在群里播报一条抽奖信息；从群里发布则不再重复播报（回复本身就在群里）。
- **私聊发密钥的顺序**：先私聊、后发群公告。这样公告里能准确写出「谁没收到私聊、请自助补领」，而不是发完公告才发现投递失败。
- **私聊失败兜底**：OneBot 系（aiocqhttp）在「未加好友 / 被风控」时，协议端会让 `send_private_msg` 抛 `ActionFailed`，而适配器不做捕获，插件据此判定投递失败，把该中奖者标记为「待补领」并在公告里点名；中奖者发送「抽奖 领取」即可重新投递。

  ⚠️ 这个判定并不万能：`Context.send_message` 的返回值语义是「是否找到平台适配器」而非「是否送达」。如果某个适配器自己吞掉了错误，插件就感知不到，只能靠中奖者主动发「抽奖 领取」。
- **剩余密钥私聊告知发布者**：开奖后如果密钥池还有没送出的（名额没报满、密钥多设了、或本场没开私聊发奖），插件会**私聊发布者**列出这些密钥明文，群公告里只提条数（`另有 N 条密钥未送出`）。发布者私聊不通时，公告里会给出自助取回的办法。
- **开奖后仍可取回密钥**：`抽奖 密钥 查看` / `抽奖 密钥 清空` 在没有进行中的抽奖时会自动回退到本群最近一场，所以开奖后密钥不会「失踪」。
- **密钥绝不上群**：`抽奖 密钥 查看` 走私聊；群公告、状态、名单里只出现密钥数量。管理面板里密钥默认打码。
- **名额受密钥池限制**：密钥模式下，实际开奖名额 = `min(设置名额, 剩余密钥数)`，避免抽出拿不到密钥的中奖者。
- **定时开奖持久化**：开奖时间写在数据库里，插件启动后由后台循环每 `check_interval_seconds` 秒扫描一次；停机期间错过的开奖会补开。若到点开奖失败（例如密钥池为空），插件会取消该定时并在群里提示管理员，不会反复重试刷屏。
- **数据**：SQLite（`lottery.db`），含抽奖场次、报名名单、密钥池（记录每条密钥发给了谁）、中奖记录。

## ❓ 常见问题

**Q：群里发「抽奖 参与」没反应？**
A：AstrBot 默认需要唤醒前缀。用 `/抽奖 参与`，或 @机器人 后发送；也可以在插件配置里把「允许不带唤醒前缀使用」打开。

**Q：中奖者没收到私聊密钥？**
A：多数是没加机器人为好友，或平台风控。让中奖者私聊机器人发送「抽奖 领取」即可补领；公告里也会点名提示。

**Q：为什么密钥一定要私聊设置？**
A：群里发的任何消息全群都能看到，密钥一旦明文出现在群里就等于作废。插件因此强制走私聊，并对误发到群里的消息做拒绝 + 撤回处理。如果机器人不是群管理员、无法撤回，那条消息就留在群里了——请立刻把这批密钥作废换新。

**Q：机器人不是群管理员，撤回失败怎么办？**
A：插件会明确回复「原消息未被撤回」之外的措辞并给出私聊指引；此时那批密钥已经泄露，建议直接弃用，重新生成一批私聊发送。

**Q：私聊里提示「机器人不在群 X 里」？**
A：插件在发布前会确认机器人在该群。OneBot 系（NapCat / Lagrange / LLOneBot）会调 `get_group_list` 核对；如果群号写错了或机器人被踢了，就是这个提示。非 OneBot 平台拿不到群列表，会退化为「该群此前有过抽奖记录」，全新群请先在该群内发布一次。

**Q：群主为什么不能在私聊里管理抽奖？**
A：私聊消息里拿不到「群主 / 群管理员」身份，而按群号操作等于跨群写权限。如果放开，任何人都能私聊机器人往任意群发抽奖。所以私聊只认 AstrBot 全局管理员 + 插件配置里的管理员；群主请直接在本群操作。

**Q：群里发布的抽奖，别人发「抽奖 参与」却说没有进行中的抽奖？**
A：v1.0.0 有这个 bug，v1.0.1 已修复，升级即可。原因是 AstrBot 开启 `unique_session`（会话隔离）后，群消息的会话标识会变成 `{用户ID}_{群号}`，旧版本拿它当群标识，于是抽奖被存成了「每人一份」，别人自然找不到。升级后插件会自动把历史数据归一化回真实群号，已有记录不会作废。

  如果你在公告里看到 `群 1626810822_762429641` 这种带下划线的群号，那就是这个 bug 的痕迹。

**Q：能不能一次发多个奖品等级（一等奖 / 二等奖）？**
A：当前版本一场抽奖对应一种奖品与一个名额数。多等级可以连续发布多场，或提 Issue 说明需求。

**Q：密钥池填少了会怎样？**
A：开奖名额会自动收缩到密钥数量，公告里会注明「密钥池不足，N 位中奖者暂未拿到密钥」。建议先补齐密钥再开奖。

**Q：设了 3 个名额 3 条密钥，但只有 2 人报名，剩下那条密钥去哪了？**
A：不会丢。插件会在开奖后**私聊发布者**，列出没送出的密钥明文和原因；群公告里只写「另有 1 条密钥未送出」，不泄露内容。之后你随时可以用 `抽奖 密钥 查看` 取回（开奖后也能用，会自动回退到本群最近一场），或在管理面板的场次详情里看。不需要了就 `抽奖 密钥 清空`。

- 数据落在 `data/plugin_data/astrbot_plugin_group_lottery/`，卸载插件不会自动删除
- 密钥以明文存在本地 SQLite 中（私聊投递需要原文），请自行做好服务器权限管理

## 🧪 开发

```bash
cd data/plugins/astrbot_plugin_group_lottery
python -m pytest tests -q        # 127 项测试，不需要启动 AstrBot
python -m ruff check .           # 代码检查
python tests/make_logo.py        # 重新生成 logo.png
```

测试通过 `tests/conftest.py` 注入的 astrbot 桩模块运行，因此无需安装 AstrBot 即可验证
时间解析、密钥解析、开奖引擎、SQLite 存储、文案渲染，以及完整的命令流程。
